Table Champ Android app

This repository contains a Kotlin Android app for learning multiplication tables with modes such as Practice, Speed Rush, Survival, Memory Match, and Boss Battle.

How to run:
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Run the app on an emulator or device.

Notes:
- Placeholder sound files are included under app/src/main/res/raw as text placeholders.
- Replace them with actual .mp3 or .wav files if you want real sound effects.
